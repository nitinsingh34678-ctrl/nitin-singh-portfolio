Portfolio project structure

index.html                    Main portfolio page and semantic content
style.css                     Base layout and component styles
design.css                    Portfolio design layer and visual styling
script.js                     Main application logic and integrations
design.js                     Design-layer interactions and portrait effects
profile-config.js             Public profile links and profile details
cloud-config.js               Supabase URL, publishable key, and owner email
SUPABASE_SETUP.md              Supabase and deployment setup notes
OWNER_MAGIC_LINK_TEMPLATE.html Supabase magic-link email template

auth/confirm.html             Secure magic-link callback
supabase/schema.sql           Database table and RLS policies

assets/                       Portraits, backgrounds, project images, and certificates

Important:
- Keep these relative paths consistent with index.html and deployment settings.
- Never put a Supabase secret/service_role key or database password in frontend files.
- The public client configuration must use only the project's publishable key.
